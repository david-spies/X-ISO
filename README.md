## X-ISO
X-ISO Disc Image Converter and Burner
### Written in python and using Tkinter for the GUI

### Prerequisites
* import tkinter as tk
* from tkinter import ttk, filedialog, messagebox
* import threading
* import os

### Installing / Running

* Save the code as X-ISO.py
* Run it from IDLE or command line: python X-ISO.py
* The application window should appear

### Features Working:

* Convert tab with file browser
* Progress bar with real-time updates
* Burn disc interface
* Virtual drive mounting
* All Tools menu items
* Complete conversion workflow: Tools > Convert > Browse > Save As > Convert > Success message

### Dependencies

* Python 3.14

Built with prompts utilizing Claude AI - python and Tkinter GUI library.
